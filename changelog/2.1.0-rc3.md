# Starlight 2.1.0-rc3 Changelog

## AINB Editor:
- Fixed new Element_Simultaneous nodes having their EndPolicy and ResultPolicy misrepresented as strings instead of ints
- Fixed redefinitions of base Element nodes in the .eainbdef, they now get overridden instead of duplicated by their respective base classes
- Fixed users being able to write unguarded data into the wrong type of variable
- Made frustum culling optional (see Preferences > Starlight > AINB > Enable culling optimization for low end devices)
- Added explicit F32Selector and StringSelector support, as well as a dummy Element_Expression class (currently just routes through the default node class, but support would be cool if I can pull it off)
- Made output handles properly fill when they have a connection
