AINB Editor:
- Fixed newly added nodes losing the "Is Output" flag on Float/Int/String/Vec3f input parameters that use their default value, causing new nodes to save incorrectly compared to vanilla data
- Fixed UserDefined (module) nodes not receiving their required Generic plug entry when a new connection was drawn to one of their inputs, extending the rc2 fix that previously only covered Selector and Expression node types
- Added the Blackboard Palette: drag a Local Blackboard entry onto a node's input or internal parameter to link it. Linked values now show as a distinct colored chip with an unlink button instead of looking identical to a plain literal default, and already-linked values are recognized automatically on load
- Fixed Element_Sequential nodes being forced to at least 2 output connections; a single connection is valid in-game and previously failed to save/validate correctly
- Fixed the Local Blackboard list throwing an ImGui ID conflict when multiple entries share the same name, which real game data does legitimately
- Fixed per-parameter pin labels being rebuilt and re-measured every visible frame instead of once, contributing to stutter while panning/zooming large graphs
- Fixed a Blackboard drag-drop check running on every visible input/internal parameter every frame regardless of whether anything was actually being dragged
- Fixed the graph's link topology (which output pins are connected) being recomputed from scratch every frame instead of only when the graph actually changes
- Fixed the off-screen culling margin growing unbounded at low zoom, pulling large numbers of far-off-screen nodes into full per-frame draw cost on spread-out (e.g. auto-laid-out) graphs

Map Editor:
- Fixed actors sometimes not being recognized as needing a physics hash even when they do. The rigid body/shape detection picked whichever "Physical" or "Collision" entry an actor happened to list last instead of specifically preferring "Physical" (the real dynamic rigid body), so actors whose data listed a static Collision entry after the Physical one silently failed to generate their physics hash
- Fixed an actor info lookup that could never actually report "not found", silently polluting the actor info table with blank entries for every unrecognized actor instead of correctly treating them as unrecognized
- Moved "play" button to a less intrusive and apparent place.

General:
- Added a VSync toggle (Preferences > Starlight > General). If the AINB graph (or anything else) feels stuttery while otherwise running fine, try turning this off, with VSync on, a frame that overshoots its budget by even a fraction of a millisecond misses the display's refresh window entirely and has to wait for the next one.
- Added a Performance Stats overlay for the AINB editor (Preferences > Starlight > AINB), breaking down per-frame timing (node drawing, link resolution, the node-editor library's own cost, and real frame time including present/vsync) for diagnosing stutter
