# Starlight 2.1.0-rc2 Changelog

## AINB Editor:
- Added undo/redo (Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y), covering node/link creation and deletion, blackboard entry creation/deletion/type changes, and entry point creation/deletion.
- Added node copy/paste (Ctrl+C / Ctrl+V, or via right-click), duplicating a node's type and parameter values with all connections and identity stripped; pasted nodes spawn at the cursor position.
- Added Delete key support for removing selected nodes and links.
- Fixed node deletion not updating Command entry points, entry strings, and replacement-table node references, which could silently misdirect or corrupt them when a non-last node was deleted.
- Fixed clicking a node's title/name requiring two clicks to select it, since the header text didn't participate in the node editor's click hit-test.
- Fixed new entry points (Commands) not being covered by undo/redo.
- Fixed changing a blackboard variable's type silently corrupting other variables' indices on save, since the type-based re-bucketing that happens at save time wasn't reflected in the editor's own state until then.
