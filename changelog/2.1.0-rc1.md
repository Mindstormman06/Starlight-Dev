# Starlight 2.1.0-rc1 Changelog

## AINB Editor:
- Fixed several crashes when saving certain AINB files due to unvalidated array indices.
- Fixed node and command GUIDs being regenerated on every save instead of preserved.
- Fixed blackboard ID and parent blackboard ID being discarded and replaced with placeholder values on save.
- Removed a large, inaccurate algorithm that tried to reconstruct node input/output links from scratch instead of preserving what was actually in the file.
- Fixed precondition nodes being recomputed and overwritten instead of preserved.
- Fixed duplicate expression (EXB) functions not being deduplicated correctly.
- Fixed several fields incorrectly saving as placeholder text or the file's own name instead of being left empty.
- Fixed string pool corruption caused by reserving the first string slot for an empty string, which doesn't match the game's own format and could corrupt most string references in affected files.
- Fixed global parameter types (Int/Float/String/Bool/etc.) being read in the wrong order, causing blackboard values to load as the wrong type.
- Fixed a crash and data loss that could occur when a node's input or output didn't fall under the parameter type it was expected to.
- Fixed attachment parameters being read with the wrong byte layout, corrupting attachment data.
- Fixed attachment names sometimes being corrupted by an internal hash value.
- Fixed the child replacement table writing invalid data for "remove child" and "remove attachment" entries, which corrupted the rest of the table.
- Fixed selector plug sizes (String Selector/Int Selector) not accounting for node type, breaking some selector nodes.
- Fixed Bool Selector, Float Selector, and Expression nodes missing part of their plug data.
- Fixed expression-driven inputs incorrectly being marked as using a default value.
- Fixed a node flag that was misidentified as "resident node" and corrupted by a flawed recompute step; it's actually the "is root node" flag and is now preserved as-is.
- Fixed Selector and Random Selector nodes losing their per-entry blackboard references, including Float Selector's independent min/max blackboard references.
- Fixed XLink actions being discarded entirely when saving.
- Fixed the BSA Brain Verb/Form Change updater plug not being handled, corrupting those specific nodes.
- Fixed the blackboard vector component (X/Y/Z) on Float inputs and properties not being saved.
- Fixed output "is linked" flags being reset incorrectly instead of only being added when actually needed.
- Fixed expression and blackboard-driven inputs being misidentified as direct node links.
- Fixed a leftover blackboard reference bleeding into unrelated plug data on nodes that had both a blackboard-linked child plug and a string/int input default.
- Fixed module input parameters losing their "sets a blackboard value" marker on save.
- Node frustum culling for improved performance.
